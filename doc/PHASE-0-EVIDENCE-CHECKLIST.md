# JOBEN NETWORK — Phase 0 Evidence Checklist

This checklist is the minimum release evidence package defined by the Arbitrum
Immune System roadmap. A checked item must point to a public record, reproducible
test, or official source. A placeholder or “probably” is not evidence.

## Eligibility and participation

- [x] Official rule reference and last checked date
- [ ] Participant/team confirmation
- [ ] Final submission deadline rechecked immediately before submission
- [ ] Session/workshop participation log

## Network and contract

- [x] Selected network and chain ID locked: Arbitrum Sepolia / `421614`
- [ ] Arbitrum One fallback decision rechecked if final rules change
- [ ] Contract source and pinned compiler version
- [ ] Deployment transaction hash
- [ ] Deployed contract address
- [ ] Explorer URL
- [ ] Contract verification URL, when available

## Attestation, gate, and invalidation

- [ ] Evidence hash and canonicalization test output
- [ ] Attestation transaction hash
- [ ] Registry read-back showing chain and subject binding
- [ ] Admission-gate interaction and accepted result
- [ ] Invalidation transaction hash
- [ ] Registry read-back showing invalidation
- [ ] Follow-up admission rejection or escalation

## Presentation and limitations

- [ ] Screenshots or recording show the same chain/network as the records
- [x] Demo scenario is labeled `DEMO FIXTURE`
- [x] Fixture/live boundary is documented
- [x] Known limitations and testnet/mainnet labels are documented
- [ ] Public evidence contains no keys, seed phrases, API keys, or raw secrets

Unchecked items are intentionally not represented as complete. Phase 0 locks the
contracts and acceptance criteria; deployment and on-chain evidence belong to
Phase 3 and must not be backfilled with simulated claims.
